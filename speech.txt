🌿 SLIDE 5 — AURAPATH (MOST IMPORTANT)
================================================================================

"Now, our most important feature — AuraPath.

AuraPath is a health-first routing engine.
Where Google Maps optimizes for speed, AuraPath optimizes for your health.

[PAUSE]

Here's exactly how it works — step by step:

  Step 1: You type in a starting point and a destination
          in our live search bar.
          The search bar uses real geocoding —
          it looks up actual map coordinates for whatever location you type.

  Step 2: We call the OpenRouteService API —
          a real, open-source routing service —
          and it gives us multiple possible routes between your two points.

  Step 3: For each route, we use a library called Turf.js
          to sample dozens of GPS points along that route's path.

  Step 4: At each sampled point, we check our AQI hexagonal grid —
          which is a pollution map overlaid on the city,
          divided into small hexagonal zones —
          and we read the air quality value for that exact location.

  Step 5: We average all those AQI readings across the full route
          and compute a Health Score for each route out of 100.

  Step 6: We present you with two options:
          👉 Cleanest Route — highlighted in green on the map
          👉 Fastest Route — shown as a grey dashed line

  You can see the estimated travel time, distance,
  the health score, and the average AQI exposure for each route.

  Then with one tap — you can open it directly in Google Maps
  for real turn-by-turn navigation.

[PAUSE]

  ⚠️ [If asked: 'Is this real or simulated?']
  The routing is real. We call a live API (OpenRouteService), perform real
  geospatial computation using Turf.js, and query a real AQI hexagonal grid
  that we built for Kolkata. The algorithm is genuine and functional.

  ⚠️ [If asked: 'Why only Kolkata?']
  AuraPath in its current version is optimized for Kolkata —
  that is our prototype city. The full technical architecture is built and working.
  Expanding to other cities is Phase 1 of our roadmap.
  The map clearly shows a 'Beta: Optimized for Kolkata' notice so users know.

  ⚠️ [If asked: 'What is a hexagonal grid?']
  Instead of dividing the city into squares, we divide it into hexagons.
  Hexagons are a better shape for geographic data because the distance from
  the center to every edge is equal — so pollution readings are more
  geometrically accurate and fair across all directions."

✅ QUICK Q&A CHEAT SHEET — READ THIS BEFORE PRESENTING
================================================================================

Q: Is the data real?
A: Yes. Weather from Open-Meteo, AQI from WAQI — both live APIs.

Q: Is routing real?
A: Yes. OpenRouteService is a real routing API. Turf.js is a real geospatial library.
   The AQI grid is a real GeoJSON file we built for Kolkata.

Q: Why only Kolkata?
A: Kolkata is our prototype city. AuraPath's architecture is complete — expanding
   to more cities is Phase 1 of the roadmap.

Q: Are IoT sensors real?
A: No. System Status uses mock data. Real sensor hardware is Phase 3 (future scope).

Q: What is a hexagonal grid?
A: The city's map is divided into hexagonal zones. Each hexagon stores an AQI value.
   Hexagons are more geometrically accurate than squares for spatial data.

Q: Why hexagons and not squares?
A: Because the distance from a hexagon center to any edge is equal — unlike squares
   where diagonal neighbors are farther than adjacent ones. Better for pollution spread.

Q: What is Turf.js?
A: An open-source JavaScript library for geospatial math — sampling points along a
   route, doing polygon intersections, calculating distances on a map.

Q: What is OpenRouteService?
A: A free, open-source routing API — similar to Google Maps Directions API,
   but without cost restrictions or usage caps.

Q: Is the app deployed?
A: Yes. Live on Vercel, which is a cloud deployment platform optimal for React apps.

Q: What is the role-based login?
A: Two roles: Resident (regular user with dashboard + routing + alerts) and
   Admin (same as Resident + System Status portal).

Q: What are PM2.5, CO2, noise in alerts?
A: PM2.5 = fine particles smaller than 2.5 micrometres — the most harmful to lungs.
   CO2 = carbon dioxide — high levels cause drowsiness and respiratory issues.
   Noise = decibel level — excessive noise is also a WHO-recognized health pollutant.

Q: Does the app work offline?
A: No. EcoByte requires an internet connection to fetch live API data.

Q: What about ML / predictions?
A: Not in the current version. Our roadmap includes predictive AQI modeling —
   but we are honest that ML is not yet implemented.
